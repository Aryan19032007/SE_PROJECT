# 🔧 FixBit - Mobile Repair Platform

## 📌 Project Overview

FixBit is a platform where:

* Users upload mobile repair issues with images
* Nearby shopkeepers send repair prices
* Works based on location

---

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js (Express)
* Database: MySQL

---

## ⚙️ Setup Instructions

### 1. Clone / Download Project

### 2. Setup Database

* Open MySQL
* Run:
  database/schema.sql

---

### 3. Backend Setup

Go to backend folder:

npm install
node server.js

---

### 4. Run Frontend

Open:
frontend/index.html

---

## 👥 Roles

### 👤 User

* Register/Login
* Upload issue + image

### 🏪 Shopkeeper

* View nearby requests
* Send price
